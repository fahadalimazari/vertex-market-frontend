# Vertex Market

Vertex Market is a modern, enterprise-grade, frontend-only marketplace application built with React, Vite, and Tailwind CSS. It is designed to be highly scalable, performant, SEO-friendly, and PWA-ready.

## Features
- **Customer Dashboard:** Order tracking, wishlist, comparisons, and reviews.
- **Seller Center:** Store management, product listings, coupons, and orders.
- **Admin Panel:** Complete marketplace management, system health, and analytics.
- **AI Shopping Assistant:** Intelligent search, support, and recommendations.
- **Localization:** Dynamic multi-language (LTR/RTL) and multi-currency support.
- **Performance & PWA:** Lazy loading, WebP images, offline support, and installable app.

## Tech Stack
- React 18
- Vite
- Tailwind CSS
- React Router DOM
- React Icons
- React Hot Toast

## Installation
```bash
npm install
npm run dev
```

## Build for Production
```bash
npm run build
npm run preview
```

## Structure
- `src/components/`: Reusable UI components organized by domain.
- `src/pages/`: Route-level pages.
- `src/context/`: Global state management.
- `src/data/`: Mock data and services.
- `src/tests/`: Automated tests.
- `src/system/`: Enterprise health and optimization systems.
